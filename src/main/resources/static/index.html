Architecture

📤 Upload → PDF / PNG / JPG / TXT stored with UUID filename
🖼️ Preprocess → Grayscale · Gaussian Blur (3×3) · Otsu Threshold · Contrast Stretch
🔤 OCR → PDFBox (digital PDFs) · Tess4J (scanned images) · Graceful fallback
✂️ Chunk → 500-char sliding window with 100-char overlap & sentence-boundary detection
📐 Embed → OpenAI text-embedding-3-small (1536-dim) OR local n-gram TF-IDF (384-dim)
🔍 Retrieve → Cosine Similarity Top-K vector search: cos(θ) = A·B / (‖A‖·‖B‖)
🤖 Generate → GPT-4o-mini RAG answer with source citations / Local extractive fallback
